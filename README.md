#  Amazon Product Card Component

A clean, modern, and dynamic e-commerce product card modeled after the Amazon product page layout, built using vanilla HTML5, CSS3, and JavaScript.

##  Features
- **Dynamic Data Binding:** Product details (name, rating, price, MRP, discount, badge, and image) are populated dynamically using a JavaScript object.
- **Amazon-Inspired UI:** Features classic e-commerce design elements like "Deal of the Day" red badges, struck-through MRP, green discount texts, and star ratings.
- **Modern Layout:** Centered using CSS Flexbox with clean box-shadows, rounded borders, and a well-structured image container.

##  Tech Stack
- **HTML5:** Semantic and clean markup structure
- **CSS3:** Flexbox, custom styling, typography, and responsive design
- **JavaScript (ES6):** DOM manipulation and object-based data injection
